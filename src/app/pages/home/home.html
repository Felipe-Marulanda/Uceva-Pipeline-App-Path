Inicio

Esta es la segunda aplicación de nuestro laboratorio de pipelines. La hicimos con Angular y se publica sola en GitHub Pages cada vez que subimos cambios a la rama main.

La diferencia con la primera aplicación está en las direcciones. Aquí no se usa el símbolo #: si miras la barra del navegador vas a ver rutas como /home, /about o /contact, igual que en cualquier sitio web normal.

Usa el menú de arriba para recorrer las tres páginas. También puedes abrir cualquiera de ellas directamente desde la barra de direcciones o recargarla con F5, y debería seguir funcionando.

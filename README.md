# Uceva Pipeline App Path

Aplicación Angular del laboratorio de CI/CD con Path Location Strategy.

## Desarrollo local

Instala las dependencias y ejecuta el servidor:

```bash
npm install
npm start
```

La aplicación estará disponible en `http://localhost:4200/` y sus vistas son:

- `/home`
- `/about`
- `/contact`

## Build

```bash
npm run build
```

La salida se genera en `dist/pipeline-app/browser`.

El pipeline de GitHub Actions será agregado posteriormente.
